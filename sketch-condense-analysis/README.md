# Sketch-Condense Analysis Utilities

Plotting and analysis helpers used alongside the Sketch-Condense project.

> This project directory is **not** the official implementation of the
> paper. It contains only figure-generation and summary scripts; the
> training and evaluation code lives in the main project directory and is
> not included here.

## Scripts

- `src/plotting.py` - regenerate the paper figures from exported metrics
- `src/summary.py` - aggregate metrics across seeds
